Passive Loop Glossary

这是 Lesson 10 起步阶段的速查表，用来固定术语，避免同一个词在不同课里意思漂移。

核心术语

Lesson
工程推进和教学推进的最小阶段单位。工程 Lesson 和 teach lesson 可以一一对应，但编号独立。
Part
单节课内部的固定结构。当前项目默认是 Part 1 Akashic 源码课，Part 2 Amadeus 复现练手。
Session
上下文、历史、持久化和检索的归属边界，不等于网页页签，也不等于一次模型请求。
Turn
一次用户输入到一次 agent 处理再到一次回复的执行单位。一个 session 里会有很多个 turn。
Passive Loop
被动回复路径上的多步推理循环：模型回复 tool calls，执行工具，再把结果回灌给模型，直到拿到最终回复。
Reasoner
持有 passive loop 主控权的运行时协调者。它决定何时调模型、何时执行工具、何时结束。
tool_chain
运行时观测视角下的工具调用链，用于 trace、持久化、eval 和解释系统行为，不直接等同于 LLM 上下文。
source_ref
用于把 memory / retrieval / search 的结果回指到原始消息或证据来源的引用标识。
eval
可复跑的行为验证资产，用来判断当前 Akashic 对齐切片是否稳定，防止后续演化时漂移。
gap audit
阶段结束时对照 Akashic 做的缺口审计：哪些已经复现，哪些还没复现，哪些边界不能偏离。
