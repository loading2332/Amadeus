# 重塑灵动侧栏：实施计划

## 实施顺序

1. 为会话日期分组新增纯函数与 Vitest 用例，覆盖今天、昨天、更早、未来、无效和空时间。
2. 重构 `SessionSidebar`：删除 `68px` 收起面板，改用主题语义色、低装饰新对话行、分组列表和精简会话项。
3. 调整 `App` 桌面侧栏外壳为 `280px -> 0px`，保留折叠偏好持久化，并把桌面展开/新建所需状态与事件传给 `ChatView`。
4. 移除 `ChatView` 顶栏和会话标题，在桌面收起态浮动显示“展开侧边栏”和“新对话”图标；移动端以同样的浮动形式保留 Drawer 入口。
5. 将空会话欢迎提示改为时间线内双向居中，并在首条 turn mutation 进入 pending 时立即隐藏。
6. 调整 Composer 输入槽左内边距，消除文字起点与胶囊圆弧的冲突，同时保持单行和多行对齐。
7. 将“回到底部”收敛为纯向下箭头圆形按钮，仅以 `aria-label` 保留辅助技术语义；移除 Tooltip 和点击涟漪。点击后平滑滚动，使用 returning ref 隔离中间滚动事件，按钮到达实际底部后才稳定退出。
8. 更新 Playwright 场景，验证完全收起、刷新持久化、收起态新建入口、欢迎提示居中及发送后消失、Composer 几何、回到底部按钮形状与无悬停提示、分组、主题切换与移动 Drawer。
9. 运行类型、静态检查、构建和聚焦 E2E，并检查桌面/移动端深浅主题截图。
10. 为首屏连接、会话内容加载、新建会话和消息发送补充就近失败反馈；重试必须回到现有 query/mutation 边界。
11. 为发送失败补充草稿保留与重试测试，为新建失败补充恢复测试。
12. 调整桌面轮内与轮间距，并用 Playwright 几何断言验证分组关系。
13. 用真实 FastAPI/PostgreSQL 场景验证首条消息摘要在侧栏即时更新并在刷新后保持，不在前端复制标题算法。

## 验证命令

在 `frontend/` 目录执行：

```powershell
npm test -- --run
npm run typecheck
npm run lint
npm run build
npx playwright test e2e/chat.spec.ts
```

若项目脚本名称与上述预期不同，以 `frontend/package.json` 中现有脚本为准，并记录实际执行结果。

## 审查门槛

- 纯函数测试证明本地日历日分组边界，不依赖执行机器的固定时区。
- DOM 中不存在桌面展开/收起两套同时可交互的侧栏。
- 桌面收起态存在两个明确的可访问入口，移动端不存在重复桌面入口。
- 侧栏没有固定深色背景、固定白色文字或常驻时间戳。
- `prefers-reduced-motion` 覆盖宽度与内容过渡。
- 现有主题、创建会话、流式消息及 Markdown 用例无回归。
- 失败恢复入口靠近触发位置，重试仍调用原有 query/mutation，不新建第二套请求状态。
- 标题公共行为由真实后端 E2E 证明，浏览器路由注入仅用于模拟网络失败，不用于冒充后端持久化验证。

## 回滚点

- 分组逻辑与展示可独立回滚，不影响会话选择和创建流程。
- 浮动入口与 `0px` 外壳必须成对保留或回滚，避免用户失去展开入口；时间线顶部留白也必须同步保留，避免入口覆盖消息。
- `Inter Variable` 作为生产依赖随 Vite 构建，本地字体加载失败时按主题字体栈降级，不影响聊天运行时。
- 不变更 `SIDEBAR_COLLAPSED_STORAGE_KEY`，防止已有用户偏好失效。
