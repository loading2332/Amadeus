# 重塑灵动侧栏

## 目标

将当前桌面侧栏从固定深色、保留窄栏的硬切换，调整为更轻、更连贯的聊天导航体验：默认展开，用户可将其完全收起；收起后仍能从聊天区快速展开侧栏或创建新对话。移动端继续使用覆盖式会话抽屉。

在侧栏与聊天主体稳定后，继续完善桌面 Web 的核心反馈：失败的加载、新建和发送操作必须可在原位置恢复；连续对话需要形成清晰的“一问一答”视觉分组；会话标题使用首条用户消息的持久化摘要。

## 已确认事实

- 桌面侧栏展开宽度保持 `280px`。
- 桌面侧栏收起后宽度为 `0px`，不保留图标栏。
- 桌面侧栏是占位式布局，展开与收起时聊天区随之平滑调整宽度，不覆盖聊天内容。
- 收起后，聊天区左上角显示“展开侧栏”和“新对话”两个纯图标入口。
- 移动端继续使用 MUI Drawer 覆盖层，不采用桌面的宽度过渡。
- 主题按钮保持纯太阳/月亮图标和二值切换，不增加主题文字或多选框。

## 需求

- 侧栏背景、文字、分隔与交互状态必须使用 MUI 主题语义色，同时适配深色和浅色主题。
- 展开态仅渲染一套侧栏内容，不再保留独立的 `68px` 收起面板。
- “新对话”表现为低装饰的导航行，保留图标和文字，但不使用强调描边按钮。
- 会话列表按当前本地日期分为“今天”“昨天”“更早”；无效或缺失时间稳定归入“更早”。
- 会话行仅显示标题，移除固定聊天图标和长期显示的时间戳。
- 当前会话使用柔和、低对比的主题背景表示，不表现为独立卡片。
- hover、pressed 与键盘 focus 必须有克制且清晰的反馈。
- 展开/收起过渡目标为 180–220ms；系统开启减少动态效果时应取消过渡。
- 折叠偏好继续通过现有本地存储边界持久化。
- 不增加后端尚未支持的会话重命名、删除或更多操作菜单。
- 首条用户消息创建成功后，会话标题使用后端生成的确定性摘要；前端不得复制摘要算法，也不得逐会话额外请求首条消息。
- 首屏连接失败、选中会话加载失败、新建会话失败和发送消息失败都必须提供就近重试入口。
- 发送失败时保留当前会话草稿；重试成功后才清空输入框。
- 桌面端同一轮中的用户消息与回答应紧密相邻，相邻两轮之间应留出更明显的间距。

## 验收标准

- [x] 桌面首次进入时侧栏宽度为 `280px`，收起后最终宽度为 `0px`，再次展开恢复为 `280px`。
- [x] 聊天区不显示顶栏和会话标题；桌面收起态不显示侧栏内容，左上角出现可访问名称明确的“展开侧边栏”和“新对话”浮动图标按钮。
- [x] 收起态点击“新对话”可调用现有创建会话流程，并正确选择新会话。
- [x] 桌面侧栏状态刷新后保持；移动端 Drawer 行为不受桌面折叠偏好影响。
- [x] 会话按“今天 / 昨天 / 更早”分组，边界基于用户本地日历日，而不是固定 24 小时差。
- [x] 会话行不再显示固定聊天图标和时间戳，选中态、悬停态在深浅主题下均可辨识。
- [x] 主题控制仍只显示太阳或月亮图标，可一键切换并在刷新后保持。
- [x] `prefers-reduced-motion: reduce` 下不执行侧栏宽度动画。
- [x] 长会话不会撑高 document；侧栏始终完整覆盖视口，右侧消息时间线独立滚动并自动跟随最新内容。
- [x] 前端单元测试、类型检查、ESLint、生产构建及相关 Playwright 用例通过。
- [x] 1440px 桌面和 390px 移动端截图中无重叠、横向溢出或不可见操作入口。
- [x] 拉丁字形由前端本地加载 `Inter Variable`，中文使用更柔和的无衬线回退字体，界面不再以系统默认字体作为首选。
- [x] 空会话欢迎提示在可用聊天时间线内水平、垂直居中；提交第一条消息后立即消失，不等待后端响应。
- [x] Composer 胶囊内的文字起点与左侧圆弧保持至少 `20px` 距离，单行垂直居中和多行按钮对齐不回归。
- [x] 用户上滚后出现的回到底部入口为纯向下箭头圆形按钮，不显示文字、Tooltip 或点击涟漪；仅保留可访问名称。点击后平滑滚动，按钮在滚动期间持续显示，到达实际底部后才隐藏且不会闪动。
- [x] 首屏连接和会话内容加载失败时可原地重试，不再要求用户刷新整个页面。
- [x] 新建会话失败时侧栏或收起态入口附近显示紧凑反馈，并可再次发起同一创建流程。
- [x] 发送消息失败后草稿保持不变；用户点击“重试发送”可成功创建 turn，成功后草稿清空。
- [x] 首条用户消息成功创建后，侧栏标题更新为该消息摘要，刷新页面后仍保持；空会话只显示“新对话”，不暴露内部 session ID。
- [x] 桌面端同轮“用户消息 → 回答”间距不大于 `24px`，相邻 turn 间距不小于 `40px`，且轮内间距小于轮间间距。

## 范围外

- 会话重命名、删除、置顶、搜索和右键菜单。
- 后端 API、数据库、Agent runtime、MemoryEngine、Telegram 或主动行为链路。
- Akashic 机制迁移；Akashic 中没有本次纯前端导航改造需要复用的运行时契约。
- 本轮新增改进不覆盖移动端布局优化、触控交互优化和屏幕阅读器专项适配。
