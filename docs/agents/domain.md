# Domain Docs

这个文件说明工程 skills 在探索 Amadeus 时如何读取领域文档。

## 探索前优先读取

- 根目录 `CONTEXT.md`，如果存在
- 根目录 `CONTEXT-MAP.md`，如果存在
- `docs/adr/` 下与当前任务相关的 ADR，如果存在

如果这些文件不存在，直接继续，不需要专门提示缺失。领域建模流程会在术语或决策真正需要记录时再创建它们。

## 当前布局

Amadeus 当前按单上下文仓库处理。除非以后新增 `CONTEXT-MAP.md`，否则 skills 默认只需要全局上下文。

## 使用项目术语

当输出需要命名领域概念时，优先使用 `CONTEXT.md` 中已有术语。如果概念缺失，应记录为术语缺口，不要随意创造相互冲突的说法。

## 标明 ADR 冲突

如果输出和已有 ADR 冲突，需要明确指出冲突点，而不是静默覆盖既有决策。
